Dataverse MCP
Cowork setup checklist

A local worksheet for tracking your own progress while setting up a Copilot Cowork plugin that connects to the Dataverse MCP endpoint. Fill in your values, check off each step, and export a sanitized copy when needed.

1. App RegistrationCreate the Entra app and capture the identity values.
2. EnvironmentEnable/configure Dataverse MCP for the target environment.
3. OAuthCreate the Developer Portal OAuth registration.
4. PluginPackage the Dataverse MCP connector for Cowork.
5. DeployUpload, assign, activate, and test the plugin.
6. Schema SkillGive Cowork logical names and table context.

Power Platform environment config

PPAC
Gotcha: the allowed MCP client uses the Entra Application / Client ID. Do not paste the OAuth registration ID here.
3

OAuth registration using Developer Portal

Create the OAuth client registration that Cowork uses through the plugin auth configuration.

referenceId
Gotcha: this OAuth registration ID is the value you use as the plugin connector referenceId. It is not the same thing as the Entra Application / Client ID.

Scope format: this checklist auto-fills the scope as DataverseOrgURL/.default offline_access. Example: https://kavoracrm.crm.dynamics.com/.default offline_access.
4

Build the plugin

Keep the plugin focused: package the Dataverse MCP connector and the minimum metadata Cowork needs.

connector package
Builder tip: use a custom helper skill or template to generate and validate the plugin package. Keep the plugin itself mostly focused on the Dataverse MCP connector so it stays reusable.

Connector snippet sanity check

This matches the agentConnectors structure for a remote MCP server: id, displayName, description, toolSource.remoteMcpServer, mcpServerUrl, and OAuthPluginVault referenceId.
