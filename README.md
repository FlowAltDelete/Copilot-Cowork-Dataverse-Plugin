# Copilot-Cowork-Dataverse-Plugin
Templated Plugin for Copilot Cowork to build a Plugin with skills per environment

## Zip	What they do with it	Who installs

cowork-plugin-builder.personal-skill.zip
Add as personal skill in Cowork (via the skills skill, or drop into their OneDrive skills folder)	Any Cowork user, one time

dataverse-mcp.cowork-template.zip
Hand to Cowork after the builder skill is loaded — say "use this template to build a plugin"	Same user, per env
